# AI 맞춤 작성

`/smart-write`에서 주제·경험·문서·사진 메모·참고 URL을 함께 받아 조사 → 전략 → 필요한 질문 → 초안 → 문체·근거 검수를 수행한다. 기존 `lib/prompts/base.ts`의 MK 문체, 금지 표현, 문단 규칙과 RSS 문체 표본·누적 프로필을 공유한다. 주제는 기존 글 유형으로 제한하지 않는다.

## 실행과 설정

- `ANTHROPIC_API_KEY`: 필수. `SMART_WRITE_MODEL`은 선택이며 기본값은 `claude-sonnet-5`.
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 네이버 웹·뉴스 검색.
- `TMDB_API_KEY`: 영화·시리즈 검색과 상세 정보. 키가 없을 때 예제 데이터를 사용하지 않는다.
- `DATABASE_URL`: 운영 환경 필수. 기존 Postgres에 `writing_runs` 테이블을 자동 생성하므로 테이블 생성 권한이 필요하다.
- 개발 환경에서 DB가 없으면 `.data/writing/`에 저장한다. 이 폴더는 Git에서 제외한다. 운영 환경에서는 파일 저장으로 대체하지 않고 설정 오류를 표시한다.

`npm run dev` 실행 후 AI 맞춤 작성 탭에서 시작한다. 같은 브라우저에서 작업 URL을 다시 열면 저장된 단계가 복원되며 ‘이어서 진행’으로 재개한다. 작업 접근 권한은 HttpOnly 브라우저 쿠키에 연결되어 있으므로 쿠키를 삭제하면 기존 작업에 접근할 수 없다.

## 포함된 기능

- PDF/TXT/MD 문서 추출, 자유 경험 입력, 사진 파일명·메모, URL 복합 입력. 문서당 40,000자, 전체 문서·메모 100,000자, 첨부 20개, URL 6개 제한.
- 네이버 웹·뉴스, TMDB, 공개 원문 읽기. AI용 사용법·한계는 `docs/writing-tools/`에서 관리하며 서버의 도구 등록부가 실행을 제한한다.
- 검색 요약과 확인한 원문을 별도 출처로 저장. 작품 후보가 여러 개면 확인 질문을 표시한다. 검색 실패·미설정·결과 없음은 구분해 기록한다.
- 독자·핵심 질문·관점·목차를 표시하고 전략을 수정해 다시 작성할 수 있다.
- 제목 5개, 본문, 필요시 정보표, 사진 삽입 위치, 해시태그, 출처, MK 시그니처를 HTML로 렌더링한다. 생성된 텍스트는 이스케이프하고 굵은 강조만 허용한다.
- 사용자 경험·출처·문체 검수와 최대 2회 자동 수정. 남은 문제와 자료 한계를 결과 옆에 표시한다. 자동 검수는 사실 정확성이나 개인 문체의 완전한 재현을 보증하지 않으므로 최종 원고를 확인한다.
- 작업 버전·잠금으로 중복 실행을 제한하고 실패 시 마지막 저장 단계에서 재시도한다.

사진은 픽셀을 분석하지 않고 사용자가 입력한 메모로 배치한다. 반복되는 팀·행사 정보는 경험란이나 문서로 입력한다. 1차 실행은 열린 브라우저가 단계별 요청을 이어가는 방식으로, 탭을 닫은 뒤 계속 실행하는 worker, 부분 문단 수정, Sheets 내보내기, 네이버 직접 발행은 후속 범위다.

## 코드와 API

- `components/smart-write/`: 전용 React 상태 훅과 입력·전략·질문·결과 UI. 기존 `/write`의 전역 상태와 독립적으로 동작한다.
- `lib/writing/`: 입력·출력 스키마, 도구 등록부, 실행기, 공통 문체 조합, 검수·렌더러, 저장소.
- `GET /api/smart-write/runs`: 연결 상태 및 브라우저 작업 쿠키 초기화.
- `POST /api/smart-write/runs`: 클라이언트 UUID로 작업 생성. 동일 ID 재요청은 기존 작업을 반환한다.
- `GET /api/smart-write/runs/{id}`: 소유한 작업 조회.
- `POST /api/smart-write/runs/{id}/{advance|answers|strategy|retry|cancel}`: 버전을 확인한 단계 실행·수정.
- `POST /api/smart-write/materials`: PDF/TXT/MD 추출. 파일당 10MB 이하.

새 검색 제공자를 추가할 때 타입·등록부·입출력 검증·도구 안내서·출처 변환을 함께 추가한다. 모델이 임의 API나 검색에서 확보하지 않은 URL을 호출하도록 허용하지 않는다.

## 검증

`npm run test:smart-write`는 실제 API 비용 없이 복합 입력, 공개 주소 검사, 도구 제한, HTML 이스케이프, 근거·문체 검사, 저장·동시성, 조사→질문→작성→검수→수정 흐름과 재시도 상태를 검사한다. `npx tsc --noEmit --incremental false`, `npm run build`로 타입과 운영 빌드를 확인한다.

개발 환경에서 실제 AI 생성 및 네이버 웹·뉴스·원문·TMDB 호출을 별도로 확인했다. 브라우저 검증에서는 복합 자료 전달, 새로고침 후 질문 복원, HTML 저장, 전략 수정, 390px 화면, 기존 일반 작성 화면을 확인했다. 실제 Postgres 연결을 사용한 운영 검증은 별도로 필요하다.
