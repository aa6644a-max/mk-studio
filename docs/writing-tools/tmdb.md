# TMDB 작품 검색과 상세

도구 ID: `tmdb_search`. query는 정확한 작품명, mediaType은 movie 또는 tv다.

영화·TV를 다루는 글에서 작품 식별과 줄거리·감독·출연 등 메타데이터를 찾는다. 동명이작 후보가 여러 개면 사용자에게 연도·포스터와 함께 확인한다. 제목만 비슷한 첫 결과를 임의로 확정하지 않는다. 선택 후 서버가 ID로 상세를 조회한다.

데이터가 없으면 정보 부족으로 남긴다. API 미설정 상태의 mock은 실제 작성에 사용할 수 없다. 데이터가 실제 관람·정주행 경험이나 스틸컷의 장면 내용을 입증하지는 않는다. TV 편당 시간·총시간의 기존 추정 기본값은 근거로 전달하지 않는다.

공식 흐름: https://developer.themoviedb.org/docs/search-and-query-for-details
