# TMDB 작품 검색과 상세

도구 ID: `tmdb_search`. query는 정확한 작품명, mediaType은 movie 또는 tv다.

영화·TV를 다루는 글에서 작품 식별과 줄거리·감독·출연 등 메타데이터를 찾는다. 동명이작 후보가 여러 개면 사용자에게 연도·포스터와 함께 확인한다. 제목만 비슷한 첫 결과를 임의로 확정하지 않는다. 선택 후 서버가 ID로 상세를 조회한다.

데이터가 없으면 정보 부족으로 남긴다. API 미설정 상태의 mock은 실제 작성에 사용할 수 없다. 데이터가 실제 관람·정주행 경험이나 스틸컷의 장면 내용을 입증하지는 않는다. TV 편당 시간·총시간의 기존 추정 기본값은 근거로 전달하지 않는다.

리뷰·프리뷰에는 사용자 감상이 충분해도 작품 정보와 이미지 확보를 위해 이 도구를 사용한다. 상세 결과는 포스터 1장과 중복을 제거한 스틸컷 최대 5장을 `sources.images`로 반환한다. `imageIds`로 도입·줄거리 뒤·본론 사이에 배치한다. 짧은 글은 문단 수에 맞게 줄이며, 이미지가 없으면 가짜 URL이나 빈 스틸컷을 만들지 않는다. 사용자 사진 메모는 별도 첨부 ID로 유지한다.

이미지 URL만 제공되므로 픽셀이나 장면 내용을 확인했다고 가정하지 않는다. 특정 장면의 분위기·연출 의도를 이미지 캡션으로 창작하지 않는다. 서버는 작품명·이미지 종류·TMDB 출처를 표시한다. 포스터·스틸컷의 실제 내용까지 사용자 경험으로 삼으면 안 된다.
